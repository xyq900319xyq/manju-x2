# 分镜交付前自检 (Storyboard Self-Check)

## 触发条件

当分镜表生成完毕，准备交付给用户时，**必须**执行本技能中的四轮检查。非可选，非建议，是交付的前提条件。

---

## 🚫 第一轮：导演视觉转换完整性审查（零容忍闸门）

> **此轮不通过 → 直接重做整个分镜，不允许"补几个镜头"的修补行为。**

### 核心原则

你不是在"核对"剧本。你是以导演身份问自己一个简单问题：

**「把这个分镜表交给一个没读过剧本的人，他看完能获得和读完剧本完全一致的体验吗？」**

答案必须是"是"。如果他在任何一个地方产生疑问——"这段情绪怎么来的？""这个道具什么时候出现的？""这人为什么突然生气了？"——就是你漏了。

### 审查方法：剧本扫描法

逐句扫描原始剧本。剧本里的**每一个词**——包括形容词、副词、气氛描写、心理活动——都必须在你分镜表的某个镜头里找到了视觉对应。

**不是"台词在不在"——台词只是剧本内容的其中一种形式。你要查的是：**

| 剧本写的内容 | 必须在分镜中找到 |
|-------------|-----------------|
| 明确说出的台词 | 对应镜头中出现了 |
| 角色的心理活动/内心感受 | 转化为面部表情、肢体动作、光影变化等可画面 |
| 气氛描写（压抑、欢快、诡异） | 转化为色调、构图、运镜 |
| 角色动作描述 | 拆解为起势→落点→反应→收尾 |
| 环境描写/空间关系 | 场景建立镜头已覆盖 |
| 关键物件/道具 | 有独立镜头或画面中出现 |
| 角色之间的情绪张力 | 有反应链镜头体现 |
| 时间流逝/节奏提示 | 通过剪辑节奏或过渡镜头表达 |
| 旁白/字幕 | 有对应的视觉画面支撑，不是纯文字 |
| **每一个角色的每一个情绪变化** | 有至少一个镜头捕捉 |

### 审查清单（逐项打勾，全部通过才算过）

- [ ] 剧本第一句到最后一句话，我逐句扫过了 _____
- [ ] 剧本中每一处心理活动 → 找到了对应的视觉化镜头 _____
- [ ] 剧本中每一处气氛描写 → 找到了对应的色调/光影/构图表达 _____
- [ ] 剧本中每一个关键物件 → 有独立镜头或出现镜头 _____
- [ ] 剧本中每一个角色的每一次情绪变化 → 有反应镜头捕捉 _____
- [ ] 剧本的旁白/字幕 → 每一句都有视觉画面支撑 _____
- [ ] 闭上眼想象：一个没读过剧本的人看完分镜 → 不会漏掉任何信息 _____

### 判定

- ☑️ 7项全部打勾 → 通过，进入第二轮
- ❌ 任意一项未打勾 → **不通过。重做整个分镜。不允许修补。**

---

## 第二轮：剧本要素追踪审查

> 此轮聚焦可明确追溯的剧本要素。有遗漏可补镜，但补完后必须回头重过第一轮闸门。

### 步骤

1. **剧情点追踪**：将剧本每一个剧情节点列成清单，逐条对到分镜表中的镜头编号。
   - 记录：剧情节点 ____ → 对应镜头 ____
   - 有任何一个剧情点没有镜头覆盖 → 立即补镜

2. **台词逐句核对**：将剧本中每一句台词（含旁白/VO/字幕）列出，在分镜表中找到对应镜头。
   - 任何一句台词找不到对应镜头 → 遗漏，立即补镜

3. **角色轨迹检查**：每个有名字的角色，从"首次被提及/铺垫" → "正式出场" → "每个动作/台词" → "退场/转场"，整条轨迹在分镜表中连续可追踪。
   - 有断层 → 补过渡镜头

4. **信息完整性**：剧本中任何关键信息（地点、时间、人物关系、关键物件）都在分镜中通过画面或对白得到了传达。
   - 有信息仅在剧本出现但分镜未体现 → 补镜头或补充画面描述

### 自检清单

- [ ] 剧本每一个剧情节点 → 对应镜头编号 _____
- [ ] 剧本每一句台词/旁白 → 对应镜头编号 _____
- [ ] 每一个有名字的角色 → 完整的出场-行动-退场镜头链 _____
- [ ] 每一个场景的空间信息 → 已在分镜中建立 _____
- [ ] 剧本中没有一句对白、一个动作、一个信息点被遗漏

---

## 第三轮：增补质量审视

### 步骤

1. **逐镜标注**：对分镜表中的每个镜头标注它的功能——是"叙事推进"还是"增补"。
2. **增补类型覆盖**：检查以下增补类型是否全部覆盖：
   - 前置场景建立（宏观/中观/微观）□
   - 前置角色建立（出场铺垫）□
   - 角色特征展示（人设镜头/习惯动作）□
   - 同框过渡（关联角色间的空间衔接）□
   - 反应链（事件后的连续反应）□
   - 衔接补镜（防纯跳切）□
   - 细节拆分（笼统动作拆为关键帧）□
   - 情绪留白（必要的"沉默空气"）□
3. **减法测试**：如果一个增补镜头不同时服务于"叙事、角色、情绪"中至少两者 → 考虑删除。
4. **加法测试**：快速扫一遍全片，是否有一个"灵魂镜头"——那个让观众看完之后会记住的画面？如果没有 → 补。

---

## 第四轮（最终）：无声测试

### 步骤

1. **关掉所有对白/旁白**，仅看画面描述。
2. **推演**：仅凭画面能否理解 80% 的故事、情绪、角色关系？
   - 不能 → 补镜头（用画面叙事，而不是用台词解释画面）
3. **情绪流**：情绪曲线是否平滑？有没有意外断裂？
   - 有断裂 → 补情绪过渡镜头

---

## 不可违背

1. **第一轮为绝对闸门**：不通过则重做整个分镜，不允许修补了事
2. 四轮检查全部通过后，方可交付分镜表给用户
3. 如有任何一项不通过（第一轮以外的），必须回头修改，不允许"先交付再解释"
4. 最终交付时，在分镜表末尾标注：
   ```
   ✅ 自检通过：导演视觉转换完整 | 剧本要素全覆盖 | 增补类型全覆盖 | 无声测试通过
   ```

---

## 轮次流程

```
第一轮（零容忍闸门）
    ↓ 不通过 → 重做整个分镜
    ↓ 通过
第二轮（要素追踪）
    ↓ 有遗漏 → 补镜 → 回头重过第一轮
    ↓ 通过
第三轮（增补质量）
    ↓ 通过
第四轮（无声测试）
    ↓ 通过
✅ 交付
```
